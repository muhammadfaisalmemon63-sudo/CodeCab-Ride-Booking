# CodeCab Ride Booking System

A console-based Java ride booking app. A passenger can book a Bike, Rickshaw or Car ride, see the fare, and cancel the ride.

## OOP Concepts Used
- Abstraction: abstract class Ride
- Inheritance: BikeRide, RickshawRide, CarRide extend Ride
- Polymorphism: calculateFare() overridden in each class
- Encapsulation: private fields with getters

## Data Structure Used
- ArrayList<Ride> stores the ride history

## How to Run
1. Install JDK
2. javac RideBooking.java
3. java RideBooking
